# القهوة | Al Qahwa

واجهة ويب عربية RTL لتطبيق ألعاب اجتماعية بهوية قهوة مصرية.

## الإصدار الحالي
- واجهة رئيسية حديثة بألوان الأخضر الداكن والذهبي.
- شاشة قهوة افتراضية بطابع مصري مرسوم، مع اختيار ترابيزة ثنائية أو رباعية.
- شاشة اختيار الترابيزات وواجهة أولية للترابيزة الخاصة.
- لعبة دومينو كلاسيك محلية ضد الكمبيوتر: 7 قطع لكل لاعب، اللعب على الطرفين، السحب والتمرير، وحساب الفوز أو إغلاق الجولة.
- أساس PWA قابل للتثبيت.

## الملفات
- `index.html`: الشاشات والهيكل.
- `styles.css`: التصميم المتجاوب.
- `app.js`: التنقل والتفاعلات ومنطق الدومينو.
- `manifest.webmanifest` و`sw.js`: أساس PWA.

## حدود النسخة الحالية
شاشة القهوة والترابيزات الحالية نموذج واجهة تفاعلي وليست بيئة ثلاثية الأبعاد فعلية. إنشاء الغرف الخاصة، دعوة الأصدقاء، الحسابات، واللعب الجماعي عبر الإنترنت تحتاج Backend وربط خدمة بيانات. لعبة الدومينو تعمل محليًا ضد الكمبيوتر فقط. All Fives والشطرنج والكوتشينة لم تكتمل بعد.

## التشغيل
افتح `index.html` محليًا أو انشر المستودع باستخدام GitHub Pages.
