# القهوة | Al Qahwa

واجهة أولية متجاوبة لتطبيق ألعاب اجتماعية باللغة العربية واتجاه RTL.

## الملفات
- `index.html`: الصفحة الرئيسية.
- `styles.css`: تصميم الواجهة المتجاوب.
- `app.js`: التفاعلات الأولية.
- `manifest.webmanifest` و`sw.js`: أساس قابلية التثبيت كتطبيق PWA.

## التشغيل
يمكن فتح `index.html` محلياً للمعاينة. لتجربة التثبيت وService Worker، شغّل المشروع عبر خادم محلي أو GitHub Pages.

## الحالة الحالية
- الصفحة الرئيسية العربية المتجاوبة جاهزة.
- لعبة دومينو كلاسيك محلية ضد الكمبيوتر: توزيع 7 قطع لكل لاعب، اللعب على الطرفين فقط، السحب والتمرير، وحساب الفوز أو إغلاق الجولة.
- هذه اللعبة تعمل محلياً على نفس الجهاز؛ لا يوجد حتى الآن لعب أونلاين أو تسجيل دخول أو غرف متعددة اللاعبين أو Backend.
- All Fives والشطرنج والكوتشينة ما زالت ضمن مراحل التطوير التالية.

## تشغيل اللعبة
افتح الموقع عبر GitHub Pages أو أي خادم static، ثم اختر «دومينو كلاسيك» من الصفحة الرئيسية.
