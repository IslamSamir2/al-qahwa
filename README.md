# القهوة | Al Qahwa

واجهة أولية متجاوبة لتطبيق ألعاب اجتماعية باللغة العربية واتجاه RTL.

## الملفات
- `index.html`: الصفحة الرئيسية.
- `styles.css`: تصميم الواجهة المتجاوب.
- `app.js`: التفاعلات الأولية.
- `manifest.webmanifest` و`sw.js`: أساس قابلية التثبيت كتطبيق PWA.

## التشغيل
يمكن فتح `index.html` محلياً للمعاينة. لتجربة التثبيت وService Worker، شغّل المشروع عبر خادم محلي أو GitHub Pages.

## الحالة الحالية
هذه نسخة واجهة أولية فقط. لا تحتوي بعد على ألعاب مكتملة أو تسجيل دخول أو غرف متعددة اللاعبين أو Backend. سيتم تنفيذ هذه الأجزاء واختبارها على مراحل.
