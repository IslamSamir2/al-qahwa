# Al Qahwa — Flutter mobile

First Flutter foundation for Android and iOS. The existing root PWA files remain untouched and are kept as the visual/functional reference.

## Run locally

From this `mobile` folder:

```powershell
flutter pub get
flutter run
```

Connect an Android phone with USB debugging enabled. This first foundation includes the RTL home screen, the nine-game catalogue, navigation shell, and a first domino entry screen. Online rooms, accounts, friends, and complete game engines are subsequent milestones.
